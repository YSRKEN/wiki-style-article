# 祭礼・宗教行事（`festival`）

神社の祭礼、地域の祭り、宗教上の行事、祭事を題材にする型。出来事（事故・事件）や、単発の催しには使わない。

細かい種類: `foreign-festival`（外国の祭り・祝日）。節の並びはこのファイルに従い、Infobox だけが変わる（外国の祭り・祝日は祝日用の Infobox）。ただし外国の祭りは節の並びも変わるので、「細かい種類の差分」を見る。Infobox の項目は `sh wiki.sh type festival` で原稿の雛形を出せる。日野祭やお白石持のように、Infobox を付けない記事もある。

## 節の並び

日本の祭礼の型は「概要 → 歴史 → 祭礼次第 → おもな祭礼道具・役」。材料の 5 本のうち 3 本で確認された型で、同じ節名（「祭礼次第」「おもな祭礼道具・役」）を使う記事が複数ある。

1. 概要: 場所、時期、主催、祭りの特徴。「特徴」と呼ぶ記事もある。祭りのまちの成り立ちを先に置く記事もある（必ず置く節）
2. 歴史: 由来、伝承、変遷。「火祭の伝承と変遷」のように祭り名を入れた節名もある（必ず置く）
3. 祭礼の範囲・運営体制: 祭礼を行う地区、組織。資料があれば。「祭礼をとりまく風習と伝承組織」の節にする記事もある
4. 祭礼次第: 日程、年間の経過、神事の順序（必ず置く）。「祭礼の年間経過」「火祭りの神事」のように分ける記事もある
5. おもな祭礼道具・役: 道具や役の名称ごとに小節を立てる。たとえば「赤鬼」「天狗」「黒鬼」「司天師」「獅子頭」「子鬼」。曳山のように祭りの中心になる道具は独立の節にする
6. 関連する場所・文化財: 祭りに関連する場所、各地区の特徴と役割、文化財指定と世界遺産（資料があれば）
7. 現地情報: 交通、見学の案内（資料があれば。「交通」「現地情報」の節）

日本の 4 本のうち、神宮式年遷宮の祭事（お白石持）だけは、他の 3 本と並びが割れ、「概要 → 日程 → 奉献団 → 衣装 → 次第 → 歴史 → お白石持の意義」になっている。宗教行事・祭事は、題材に合わせて「日程」「奉献団」のような固有の節を足す。

## 導入部

第一文は、場所と時期を入れる。

```
'''祭名'''（読み）は、{県}{市}{地区}で{毎年M月D日}に行われる{祭り／祭礼行事}。
```

続く文で、主催する神社や団体、文化財の指定（重要無形民俗文化財など）、「日本三奇祭」のような肩書を述べる。肩書は出典のある呼称として書く。段落数の集計は取っていない。全類型では 4 段落以内が大半なので、概要の要約として 1〜3 段落に収める。

## 調べる観点の下敷き

- 概要: 名称、場所、時期、主催、文化財の指定。探す資料の例: 一次は神社・保存会・自治体の公式サイトと、文化財指定の記録、二次は事典・解説書
- 歴史・由来: 縁起、文献、伝承、変遷。一次は神社の社伝・縁起、二次は市町村史・神社史・民俗学の調査報告書
- 祭礼次第: 日程、神事の順序、年間の経過。一次は神社・保存会の資料、二次は民俗調査の報告書・報道
- 道具と役: 道具の名称、役の名称、衣装。一次は保存会の資料、二次は民俗学の文献・文化財の解説
- 運営体制・祭礼の範囲: 氏子、奉献団、地区、風習。二次は市町村史・調査報告書
- 文化財・社会的位置づけ: 指定の名称と年、肩書の出典。一次は文化財の指定を示す公的な資料、二次は報道・事典
- 現地情報（題材しだい）: 交通、見学の情報。公式サイトを一次にする。変わりやすいので、取得した時点を控える

祭礼は「歴史・由来」と「祭礼次第・道具・役」を別々の担当にしやすい。小さい祭りは、「概要・運営体制」「歴史」「祭礼次第・道具」の 3 つに合わせてよい。外国の祭りは、語源と神話の担当を足す。

## この類型の作法

- 由来と伝承は、誰の記述か（社伝、縁起書、市史、研究者）を名指しして書く（R01、R06）。「〜と言われている」「〜と伝えられる」を主語なしで書かない。記録で確かめられることと、伝承を分けて書く（R01）
- 開催日、行事の内容、担い手は年によって変わる。「現在」「毎年」の断定を本文で重ねず、開催の状況（中止、再開、規模の変化）は年で書く（R08）。導入部の「毎年M月D日」は出典で確かめる
- 「日本三奇祭」などの肩書と指定は、出典のある呼称として書く。地の文に「有名な」「伝統ある」「壮大な」のような評価語を足さない（R05）
- 祭礼の役・道具は、名称を小節名に使い、名称ごとに何を担うかを書く
- 現地情報（交通、見学時間、料金）は変わりやすいので、取得した時点を明示し、案内書の文体にしない（R08、R13）
- 信仰や宗派の解釈の違いは、論争に加わらず、誰の説かを書いて並べる（R02）
- 雑多な豆知識の節を作らない（R12）。関連行事は、祭礼次第や歴史の節に織り込む

## 細かい種類の差分

- `foreign-festival`（外国の祭り・祝日）: 日本の祭礼の「祭礼次第」「おもな祭礼道具・役」は使わない。節の並びは「語源 → 行事と意味 → 神話・宗教上の位置づけ → 異文化との関わりと変遷 → 現代の祭り」で、材料の見本は 1 本のみ。導入部は `'''祭名'''（読み、原語名）は、{民族}における{1年の最初の祝日}であり、{日付}に行われる祭りである。` の型。外国語の名は片仮名で書き、原語を括弧に入れる（R30）。日本から見た語ではなく、国・民族・地域を冒頭で明示する（R11）

## 第一文の例

`'''灯籠送り'''（とうろうおくり）は、岩渕県蛇島市の海沿いの地区で毎年8月15日に行われる祭礼行事。`
