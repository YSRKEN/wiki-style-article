# 人物（存命）（`person-living`）

現在も存命の個人を主題にする記事に使う。芸能・スポーツ・創作など、活動の記録が長く続く人物が中心になる。

細かい種類: `voice-actor`（声優）、`singer`（歌手）、`baseball-player`（野球選手）、`soccer-player`（サッカー選手）、`pro-wrestler`（プロレスラー）、`actor`（俳優）、`author`（作家）、`manga-artist`（漫画家）。節の並びはこのファイルに従い、Infobox だけが変わる。Infobox の項目は `sh wiki.sh type person-living` で原稿の雛形を出せる（細かい種類は、その ID を渡す）。

## 節の並び

時系列の節を先に置き、人物・作風の節、受賞・作品の一覧の節を後ろに置く。

1. 来歴: 生い立ちから現在までを時期ごとの h3 に分ける（必ず置く）。節名は「来歴」「略歴」のどちらかにそろえ、題材の資料の呼び方に合わせる。デビュー・転機・連載や出演の節目を小節名にしてよい。
2. 作風・人物像: 芸風・作風・得意分野・影響を受けた人・執筆や制作の方法を書く（資料があれば）。「作風」「趣味趣向・影響」「執筆スタイル」のように、題材に合う名前を付けて分けてよい。
3. 私生活: 家族・交際・健康など（資料があれば。置くかどうかは作法の R62 に従って決める）。
4. 年表: 来歴が長いとき、略年表を添える（資料があれば。本文の主体にはしない）。
5. 受賞歴: 受賞とノミネートを年順に並べる（資料があれば）。
6. 作品・出演の一覧: 職業に合わせて「作品リスト」「フィルモグラフィ」「出演」「ディスコグラフィ」などを置く。種類ごとに h3 に分ける。
7. メディア出演: テレビ・ラジオ・広告などの出演（資料があれば）。
8. 関連人物: 師弟・共作者・影響関係など、本文で触れた人物（資料があれば）。

存命の人物の記事では、「評価」を独立の節にせず、来歴や作風の中で触れる記事が多い。評価の資料が厚いときは独立の節にしてよい。

## 導入部

第一文の型:

```
'''氏名'''（読み、本名：'''本名'''〈読み〉、生年月日 - ）は、国の職業。
```

- 括弧に入れる順は、読み → 本名（公開されていて必要なときだけ）→ 生年月日 → 「 - 」（没年月日は空にして閉じる）。生年月日の和暦は山括弧に入れる（`1962年〈昭和37年〉12月10日` の形）。外国人は原語綴りも括弧に入れる。
- 続く文で、デビュー・代表作・受けた評価を時系列で述べる。出身地と学歴は第一段落にまとめる書き方と、キャリアから入る書き方がある。
- 所属事務所・所属団体は、第一段落で書く記事が多い。
- 段落数の目安は 1〜4 段落。短い記事は 1 段落、活動の長い人物は 3〜4 段落に伸びる。導入部にも出典を付ける（R41）。

## 調べる観点の下敷き

- 生い立ち・デビューまで: 出身地・家族構成の概略・学歴・きっかけ。一次資料は本人の公式サイト・公式プロフィール・本人の著書。二次資料は新聞・雑誌のインタビュー記事、評伝。
- 活動の経過（時期ごと）: デビュー、転機、代表作や主な出演・成績、所属の変遷。一次資料は所属先の発表・作品そのもの・公式の記録。二次資料は新聞・雑誌の記事、書籍。
- 作風・人物像: 特徴、制作や稽古の方法、影響を受けた人。二次資料の批評・インタビュー・対談を中心にし、本人の発言は誰がどこで述べたかを控える。
- 受賞・評価: 受賞歴と、批評家や関係者の評。一次資料は主催者の公式発表。二次資料は新聞・専門誌の批評。
- 作品・出演の一覧: 職業に合う一覧（作品、出演、成績、ディスコグラフィなど）。一次資料は公式の作品一覧・所属先の実績ページ。二次資料は公的な記録や専門のデータベース。
- 私生活・健康（題材しだい）: 公表されているものだけを、信頼できる第三者の出典で。担当には、否定的な内容を見つけても出典の質とともに報告させる。
- 現況: 直近の活動と、調べた時点。公式サイトと最新の報道で確かめ、調べた日付を添えて返させる。

分け方: 作品・出演の一覧は、分量が多い人物では種類ごとに担当を分ける。受賞と評価は 1 人にまとめてよい。

## この類型の作法

存命の人物は、間違いが本人への害になる。次を先に守る。

- 保守的・中立的・百科事典的に書く。肯定にも否定にも偏らない（R60）。
- 出典のない否定的な記述、貧弱な出典（テレビで見た、自分の目で見た）だけの否定的な記述は書かない。党派的なサイトやブログは出典にしない（R61）。
- ゴシップ・スキャンダル・私生活（離婚、逮捕歴・裁判歴など）は、その人物の著名性に関わる重要なものを、信頼できる第三者の出典で書く。直接調べた公的記録（資産、違反歴）は書かない。私人に近い人物は、知名度に釣り合う情報だけにする（R62）。
- 著名でない存命の人物は、正確な誕生日を書かず誕生年だけにする（R63）。
- 評論家の意見は、人物の著名性に釣り合う重要なものを、記事を損なわない形で明記してよい（R64）。
- 導入部でも、引用と存命の人物についての記述には出典を付ける（R41）。

そのほか、この類型で守ること。

- 名前は太字。日本人・中国人などは名字と名前の間に半角空白を置き、直後に（読み、生年月日 - ）を続ける。「○代目」には読みを振らない。欧米人は片仮名の名を書き、直後の括弧に現地語のフルネームを入れる（R51）。
- 第一段落に、名前・生年月日・国籍または地域・主な活動・重要である理由を入れる。日本人は日本人と明記する（R50）。
- 存命の人物は、没年月日を空欄にして、ハイフンで閉じる（R52）。生年が不正確なら「1960年ごろ」と書く。
- 通称・ペンネームは第一段落に書く。本人が公開していない本名は書かない（R53）。
- 敬称は冒頭で紹介するときにとどめ、以降の文では使わない（R54）。
- 血液型のような、業績や特筆性に関係しない些末な個人情報を導入部に入れない（R56）。
- 本文は流れのある文章で書く。年表（箇条書きかどうかを問わず）を記事の主体にしない。関連人物に、番組で共演しただけの人を並べない（R57）。
- 私生活を節にするかは資料の厚さで決める。節にしない記事は、導入部や来歴の中の一文で触れるにとどめる。

## 細かい種類の差分

- `voice-actor`（声優）: 来歴の次に「出演」の節を置き、作品の種類ごとに h3 に分ける（テレビアニメ、劇場アニメ、OVA、Webアニメ、ゲーム、ドラマCD、ラジオドラマ、吹き替え、ラジオ、テレビ番組、映像商品、ナレーションの順。該当するものだけ）。各行は古いものから発表順に `* 作品名（2015年、役名）` の形にし、複数の役は読点で区切る。続けて「ディスコグラフィ」「ライブ・イベント」を置く。導入部の第一段落に事務所と出身地を書き、代表作は出典で示せるものに限る。本名は書かない。見本の秀逸・良質記事が無い類型で、この並びは執筆指針と長い記事による。出演の一覧ばかりが厚くなるので、人物像や特色の散文の節を添える。
- `singer`（歌手）: 来歴を時期ごとに厚く書く。後ろに「代表曲」「ディスコグラフィ」「主な出演」を置く。日本の歌手は「NHK紅白歌合戦出場歴」の節を持つ記事がある。曲名は「」、番組・映画・アルバムの題は『』で括る。
- `baseball-player`（野球選手）: 来歴をアマチュア時代・球団ごとに分け、「選手としての特徴」の後に、「詳細情報」の節へ年度別成績・タイトル・表彰・記録・背番号をまとめる。導入部は所属した球団とデビュー・主な実績を述べる。
- `soccer-player`（サッカー選手）: 来歴の代わりに「クラブ経歴」「代表経歴」（大会ごとの h3）を置く。後ろに「獲得タイトル」「個人成績」を置く。
- `pro-wrestler`（プロレスラー）: 来歴の後に「得意技」「タイトル歴」「入場テーマ曲」「プロレス観」を置く。導入部は所属した団体とデビュー・主な実績を述べる。
- `actor`（俳優）: 来歴の中の演技キャリアを年代ごとの h3 にする。後ろに「フィルモグラフィ」「受賞とノミネート」を置き、外国人俳優は「日本語吹き替え」も置く。音楽活動があれば「音楽キャリア」を別の節にする。
- `author`（作家）: 「作風」「主題」の節を厚くし、後ろに「おもな作品」「刊行書籍」を置く。存命の作家は材料に見本が無く、故人の作家と存命の他分野の並びを参考にしている。
- `manga-artist`（漫画家）: 来歴を出来事や連載の節目ごとに分ける。「作風」「執筆スタイル」「趣味趣向・影響」を置き、後ろに「年表」「受賞歴」「作品リスト」「メディア出演」「関連人物」を置く。

## 第一文の例

```
'''灰谷 蒼真'''（はいたに そうま、1988年〈昭和63年〉3月4日 - ）は、日本の声優。東京都出身。架空プロダクション所属。
```
