# 出来事（`event`）

事故・災害・事件・戦闘・裁判など、日時と場所のある出来事を題材にする型。細かい種類: `aviation-accident`（航空事故）、`battle`（戦闘）、`court-case`（判例）。節の並びはこのファイルに従い、Infobox だけが変わる（判例は Infobox を持たない）。Infobox の項目は `sh wiki.sh type event` で原稿の雛形を出せる。

## 節の並び

既定は、背景 → 経過 → 被害・結果 → 調査・原因 → 対応・教訓 → 影響・反応 → 関連作品・類似例。経過は時系列の小節に分ける。

1. 概要: 導入部に収まらない長い記事だけに置く（題材しだい）。置かずに「背景」から始める記事も多い。
2. 背景: 経緯、出来事に至るまでの状況。事故なら当日の便や現場の状況をここに書く。
3. 経過: 時系列で小節に分ける。時刻は24時間表記で分単位まで書く。
4. 被害・結果: 死者・行方不明者・負傷者・物的被害の数。
5. 調査・原因: 調査機関の結論を書く。原因ごとに小節を立てる。刑事事件なら「捜査」「刑事裁判」を節にする（審級ごとに小節）。
6. 対応・対策・教訓: 当事者の対応、事故後の対策、行政の動き。
7. 影響・反応: 社会への影響、各方面の反応。
8. 報道・関連作品（資料があれば）: 報道、記録作品、映像作品。
9. 類似例（資料があれば）: 類似した事故・事件。
10. 慰霊（資料があれば）: 慰霊碑、追悼の行事。
11. 異説・その後（資料があれば）: 結論と異なる説、事故機のその後など。

並びは記事ごとに割れる。原因から書き始める水害の記事や、「経緯 → 当日 → 試合直後 → その後」のように調査の節を持たない記事もある。出来事の種類に応じて、無い節は作らない。

## 導入部

第一文は次の型。国内の出来事は和暦を丸括弧で添え、外国の出来事は和暦を付けない。

```
'''名称'''（読み）は、日時に場所で発生した{事故／事件／災害}である。
```

- 通称・略称は、括弧の中か次の文で示す。略称で通すなら「（以下、A）」「以下「X」と表記」と一度断る。
- 第二段落以降で、原因と経過の要約、被害の数、調査の結果、後世への影響を書く。導入部は本文の要約にとどめ、続きをほのめかさない（R41）。
- 長さは1段落が最多で、4段落以内に収める。出典を付ける記事と付けない記事に分かれるが、引用と存命人物の記述には必ず付ける（R41）。

## 調べる観点の下敷き

- 基本事実（日時・場所・種別・規模）: 公的機関の発表、調査報告書、警察・消防の発表、新聞の第一報。
- 背景と経緯: 事故調査報告書の前提事実、当時の新聞・雑誌、関連組織の公表資料、書籍。
- 経過（時系列）: 調査報告書の時系列、裁判記録、報道の続報。時刻の基準（現地時間など）も確かめる。
- 被害と結果の数: 公的機関の集計、報告書、新聞。数字が後から改訂されていないかを見る。
- 調査・原因・捜査・裁判: 調査機関の報告書、判決文、検察・警察の発表、専門家の解説書。異説があれば別に集める。
- 対応・対策・教訓: 行政や事業者の再発防止策、制度改正の記録、関連する法令。
- 影響・反応・報道・関連作品: 新聞・雑誌の論評、書籍、映像作品、慰霊の行事の記録。
- 個人の扱い（被害者・被疑者・被告人・遺族）: 報道各社の扱いの違い、実名の扱いが論じられた記事。題材に個人が絡むときだけ立てる。

題材しだいで、「背景」と「経過」は1人に任せてよい。調査・原因が厚い事故は、原因ごとに担当を分ける。

## この類型の作法

- 個人（被害者・被疑者・被告人・遺族）に触れる箇所は、先にこの項を当てる。
  - 被疑者・加害者の実名は、出さず「男A」「（以下、A）」のように略記する記事と、書く記事に分かれる。迷うときは出さずに略記する。実名を書くなら、信頼できる出典が実名を公表していることを確かめる。
  - 存命の被疑者・被告人・関係者の記述には、存命人物の規則を当てる。出典のない否定的な記述は書かない（R61）。逮捕歴・裁判歴は、著名性に関わるものを信頼できる第三者の出典で書く（R62）。著名でない人物の正確な誕生日は書かず、誕生年だけにする（R63）。
  - 被害者・犠牲者は人数と属性（乗員・乗客など）で書き、実名を並べない。実名報道の是非が論じられた事件は、その論点を出典付きで独立の節にする記事がある。
  - 同情も非難も示さない。疑いを含む動詞（「言い張る」）は使わず「述べた」にする（R02）。
  - 単発の批判や報道を、出来事全体の重要度より大きく書かない（R03）。
  - 誤報が出典で確かめられるときは、「事件に関連する誤報など」のような節で、誤りだったことを示して扱う記事がある。
- 原因・動機は、調査機関・捜査機関・裁判所の結論を出典付きで書き、書き手の推定を加えない。結論と異なる説は、誰の説かを示して「異説」の節に分ける。
- 過去形で書く（出来事の記事は全文の約7割が「〜た。」）。
- 時刻の基準は脚注で一度示す。
- 参考文献は、事故調査報告書、書籍・雑誌記事等、オンライン資料のように種類で分ける記事がある。
- 場所は座標が付く記事がある（航空事故）。

## 細かい種類の差分

- `aviation-accident`（航空事故）: 背景は「事故当日の便」とし、経過は小節（事故の経過）に分ける。調査は原因ごとに小節を立てる。乗員の対応への評価、事故後の対策・教訓、映像作品、類似事故の節が定番。Infobox は英語の項目名が多い。
- `battle`（戦闘）: 背景 → 軍隊 → 戦場 → 経過 → 戦後 → 古戦場 → 作品。交戦勢力ごとの兵力・指揮官・損害は、Infobox に収録していない（番号付きの項目）ので、「軍隊」の節に書く。
- `court-case`（判例）: Infobox を持たない（刑事事件で Infobox を付けるなら `event` を使う）。民事は、事件の背景 → 裁判の経過（提訴に至るまで／審級ごと）→ 争点 → 判決（審級ごとの要旨）→ 影響（学説・後の判決への影響）→ 関連判例。刑事は 概要 → 事件発生 → 捜査 → 第一審 → 控訴審 → 裁判後 → 評価・影響。見出しに判決の日付・審級・裁判所名を入れる。導入部は、民事なら当事者と訴えの種類（「〜を相手取り、訴訟を起こした損害賠償請求事件である」）、刑事なら出来事の型を使う。導入部は3〜4段落になる。

## 第一文の例

`'''星見ヶ丘高架橋崩落事故'''（ほしみがおかこうかきょうほうらくじこ）は、2012年（平成24年）9月4日に月影県霧原市の星見ヶ丘高架橋で発生した橋梁の崩落事故である。`
