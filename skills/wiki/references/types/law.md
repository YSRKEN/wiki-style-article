# 法令（`law`）

法律・法令そのものを題材にする型。制定の経緯、条文の内容、改正、廃止を書く。判例・事件（訴訟の経過と判決）は `event` か `court-case` で、この型ではない。外国の法令も同じ節の並びを使うが、枠の扱いは下の「この類型の作法」を見る。

この型の概要表は、記事の最上部でなく導入部の中に置かれる。項目は `sh wiki.sh type law` で原稿の雛形を出せる。

## 節の並び

法令は「制定の経緯 → 条文 → 改正 → 廃止」。見本が少ない型なので、題材に合わせて節を足し引きする。

1. 制定の経緯: 背景、立法に至った事情、制定の過程（必ず置く）
2. 条文: 内容を主題ごとの小節に分けて書く。たとえば運賃の法令では「運賃設定の原則」「旅客運賃と料金」「貨物運賃」「その他」のように、条文の主題で分ける（必ず置く）
3. 改正: 改正の年月日と内容を時系列で書く（改正があれば）
4. 廃止: 廃止の経緯と後継の法令（廃止された法令だけ。現行の法令には置かない）

外国法は別の並びが確認されている。「国際比較 → 現行法の詳細解説 → 著作権管理サービス → 法改正の歴史 → 著作権侵害と紛争解決」で、外国の著作権法を扱った記事 1 本に基づく。制度に固有の節（管理サービスなど）は題材に合わせる。

材料の判例の記事は、学説や後の判決への影響を書く節を持つ。法令でも、運用や判例・学説への影響を述べた資料があれば、改正の後に「影響」の節を足してよい。

## 導入部

第一文は、法令名に続く括弧に読みと、公布年月日・法律番号を入れる。

```
'''法令名'''（読み、昭和23年7月7日法律第112号）は、日本の〜を定める法律である。
```

- 括弧の順は、読み、公布年月日と法律番号。年は和暦を法律番号と一続きで書く
- 外国法: `'''〜国の〜法'''（読み、原語）は、〜を保護する〜国の法律である。`
- 続く文で、制定の目的、主な内容、改正や廃止の有無を要約する。法令・判例の見本では導入部が 3〜4 段落だった

## 調べる観点の下敷き

- 法令の基本事項: 題名、公布年月日、法律番号、所管、種類、施行、効力。探す資料の例: 一次は官報・政府の法令データベース、二次は法令集・概説書
- 制定の経緯: 立法の背景、審議の過程。一次は国会の会議録・法案の資料、二次は立案担当者の解説書・法制史の文献・当時の報道
- 条文の内容: 条文の主題と趣旨。一次は条文そのもの、二次は逐条解説・基本書
- 改正: 改正の年月日、改正法、内容。一次は官報と改正法の附則、二次は改正の解説
- 廃止と後継（廃止された法令のみ）: 廃止の経緯、後継の法令。一次は廃止法の附則、二次は解説
- 運用・影響（資料があれば）: 判例・学説・後の法改正への影響。二次は判例の評釈・学術書・報道
- 外国法の場合: 制度の国際比較、現行法の詳細、改正史、紛争解決。一次は当該国の法令集、二次は比較法の文献

法令が短ければ「制定の経緯」と「条文の内容」は同じ担当にまとめてよい。

## この類型の作法

- 条文の解釈を書き手が導かない（R09）。解釈や効果は、逐条解説・学説・判例に載るものだけを、誰のものかを名指しして書く（R01、R06）。「〜と解されている」を主語なしで使わない
- 現行かどうかを「現在」で示さず、時点を年月日で書く（R08）。改正は年月日と改正法の番号を付けて書く。現行の法令に「廃止」の節を作らない
- 操作の手引き・手続の説明書にしない（R13）。条文の趣旨と沿革を書く
- 制定の経緯は、出典で確かめられた因果だけを書く。「その結果」「したがって」で書き手が因果をつながない（R09）
- 外国法は、国名を導入部の冒頭に出す（R11）。「国内法」のように基準の分からない語を使わない
- 概要表の項目は日本の法令向きである。外国法用の枠は収録していない（docs/types.md）ので、外国法で埋められない項目は無理に埋めず、種類と効力は導入部の本文で述べる
- 改正が多い法令は、変更履歴を逐一並べず、主要な改正を選んで書く（R13）

## 第一文の例

`'''灯台守職員給与法'''（とうだいもりしょくいんきゅうよほう、昭和31年3月5日法律第42号）は、日本の灯台の保守に従事する職員の給与について定めた法律である。`
