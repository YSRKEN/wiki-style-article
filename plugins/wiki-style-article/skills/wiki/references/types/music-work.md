# 音楽作品（`music-work`）

曲（シングル・楽曲）を扱う型。アルバムも同じ骨格で書く。細かい種類: `album`（アルバム）。節の並びはこのファイルに従い、Infobox だけが変わる。曲の Infobox の項目は `sh wiki.sh type music-work`、アルバムは `sh wiki.sh type album` で原稿の雛形を出せる。

## 節の並び

曲の並びを既定にする。散文の節を先に、資料の節を後に置く。アルバムは「細かい種類の差分」で変える。

1. 背景（必ず）: 制作に至る経緯、前作との関係、リリースの事情。「背景・リリース」とまとめる記事もある
2. 制作と録音（資料があれば）: 作詞・作曲・編曲、プロデューサー、録音の経緯
3. 音楽性と歌詞（必ず）: 曲調、構成、歌詞の主題。歌詞そのものは載せず、二次資料の分析を出典に書く
4. 批評（資料があれば）: 批評家・音楽誌のレビュー
5. チャート成績: 順位、認定、売上。時点と出典を明記する
6. ミュージックビデオ: 内容と公開の経緯
7. ライブ・パフォーマンス（題材しだい）: 初披露、代表的な披露、テレビ披露
8. 反響・タイアップ（話題になった曲）: 社会的な反響、受賞とノミネート、タイアップ先、SNS での広がり。節名は内容に合わせて分ける
9. カバー（資料があれば）: 他のアーティストによる演奏
10. 収録内容（収録曲）（必ず）: 収録曲を箇条書きで書く
11. クレジット（資料があれば）: 作詞・作曲・編曲・演奏・制作の担当を箇条書きで書く
12. リリース日一覧（題材しだい）: 地域・媒体ごとのリリース日を箇条書きで書く。複数の版があるときに置く

海外向け版などの別版がある曲は、版ごとに h3 を立ててよい。

## 導入部

第一文の型:

`「曲名」（読み）は、日本の{ユニット／ロックバンド／シンガーソングライター}・{アーティスト名}の{楽曲／N枚目のシングル}。`

- 曲名は「」で括る。括弧には読みを入れる
- 続けて、リリース日と媒体（配信・シングル・アルバム収録曲など）を述べる
- 第 2 段落以降に、タイアップ先、作者、音楽的特徴、チャート成績を述べる
- 導入部は 1〜3 段落で、短くてよい（100〜700 字ほど）

## 調べる観点の下敷き

- 基本情報: アーティスト、リリース日、レーベル、収録アルバム、作詞作曲、タイアップ。探す資料: アーティストとレーベルの公式サイト、公式発表（一次）、配信サービスのページ
- 制作: 背景、作詞作曲・編曲の経緯、録音。探す資料: アーティストやプロデューサーへのインタビュー、音楽誌の記事、ライナーノーツ
- 音楽性と歌詞: 曲調、構成、歌詞の主題。探す資料: 音楽誌・批評家の評論。独自に分析しない（R09）
- 批評: レビュー、評価。探す資料: 音楽誌、新聞、批評サイトの署名記事。レーベルの宣伝文は評価の出典にしない（R10）
- チャートと売上: 順位、認定、売上。探す資料: チャート運営元・業界団体の公式発表、新聞の記事
- 映像とライブ: ミュージックビデオ、ライブ披露、テレビ披露。探す資料: 公式の映像公開ページ、ライブの公式発表、新聞・雑誌の記事
- 反響と受賞: SNS での広がり、受賞、カバー、タイアップの影響。探す資料: 賞の公式発表、新聞・雑誌の記事
- 題材によって、映像とライブを合わせてよい。アルバムは、収録曲ごとの解説（楽曲）を別の観点にする

## この類型の作法

- 作品の良し悪しは地の文で断定せず、批評・受賞・チャートの出典で示す（R04）。「名曲」「傑作」と書かない（R05）
- 歌詞を載せない。引用は主題を説明する短いものにとどめる（R13）
- 音楽性や歌詞の解釈は、二次資料に載っているものだけを書く。出典に書かれていない因果を作らない（R09）
- 賞・順位・売上は、時点と出典を書く。「最近」「現在」で時点を示さない（R08）
- 曲名・作品内の小題は「」、アルバム名・書名・映画やテレビ番組の名は『』で括る（R28）
- 販売価格を並べない（R13）
- 「余談」「トリビア」の節を作らない（R12）
- 表は行と列のあるデータにだけ使う（R14）。原稿では表を使わず、リリース日やチャートは箇条書きか散文で書く

## 細かい種類の差分

- `album`（アルバム）: 「背景 → 録音・制作 → 音楽性とテーマ → 楽曲 → リリース・アートワーク → プロモーション → ツアー → 批評 → チャート成績 → 収録曲 → スタッフ・クレジット → チャート・認定 → リリース日一覧」の並びにする。「楽曲」は収録曲ごとの解説で、LP の面がある作品は SIDE A・SIDE B の h3 に分けてよい。導入部は 3〜4 段落（500〜900 字ほど）で、第一文は `『'''アルバム名'''』（読み）は、日本の{ロックバンド／シンガーソングライター}である{アーティスト名}の{N枚目}のオリジナル・アルバム。` にし、英題があれば「英題は『X』（読み）」と添える。第 1 段落に基本情報（アルバム名、アーティスト、リリース日、レーベル、ジャンル）を含め、第 2 段落にリリース日・レーベル・作詞作曲・プロデューサー・前作との間隔を述べる。批評家の評価はできる限り詳細に書く

## 第一文の例

`「ほしくず通り」（ほしくずどおり）は、日本のロックバンド・夜更かしクラブの楽曲。2023年5月3日に配信限定で発売された。`
