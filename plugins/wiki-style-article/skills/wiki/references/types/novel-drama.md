# 小説・ドラマ（`novel-drama`）

小説（文学作品）、ライトノベル、テレビドラマを扱う型。細かい種類: `light-novel`（ライトノベル）、`tv-drama`（テレビドラマ）。節の並びはこのファイルに従い、Infobox だけが変わる。Infobox の項目は `sh wiki.sh type novel-drama` で原稿の雛形を出せる。

## 節の並び

小説（文学作品）の並びを既定にする。ライトノベルとテレビドラマは「細かい種類の差分」で変える。

1. あらすじ（プロット）（必ず）: 結末まで現在形で書く。短編は 1〜2 段落でよい
2. 登場人物（題材しだい）: 主要人物だけ。1 人 1 項目の箇条書きで「人名（よみ）: 説明」にする。文学作品では置かない記事が多い
3. 作風とテーマ（作品について）（資料があれば）: 文体、解釈、象徴など。二次資料に載っているものだけを書く
4. 制作背景（執筆の経過・作品史）: 成立の事情、発表の経過、改稿。国語教材のように改稿の議論が重要な作品は、時系列で書く
5. 評価（出版と反響）（必ず）: 発表時の反響、受賞、批評、後世への影響
6. 日本語訳・翻案（題材しだい）: 外国文学は日本語訳を節にする。映像化・舞台化・漫画化などの翻案は題材に合う名前にする

材料の中では、文学作品の記事で「執筆の経過」や「発表経過」をあらすじより前に置く並びもある。

## 導入部

第一文の型:

`『'''題名'''』（読み、原題）は、{時代}の{国}の作家{作者}による{中編／短編}小説。`

- 括弧には読み、原題の順に入れる。読みが自明な英字の題は別表記だけにする
- 次の文で出版年と初出（掲載誌・刊行形態）を述べる
- 続く文に書くもの: 受賞、あらすじの要点でない作品の特徴、批評と影響、翻案
- 範囲を限る一文（「本項では〜も記述する」）を置いてよい
- 段落は 1〜3 を目安にする

## 調べる観点の下敷き

- 基本情報: 作者、初出、刊行、レーベル・放送枠、受賞。探す資料: 版元・放送局の公式サイト、奥付、初出誌（一次）
- 物語: あらすじ、主要人物。探す資料: 作品そのもの、書評、公式の作品紹介
- 成立と制作: 執筆の経緯、改稿、企画・製作の事情。探す資料: 作者へのインタビュー、全集の解題、新聞・雑誌の記事、研究書
- 作風とテーマ: 文体、主題、解釈。探す資料: 批評家の評論、研究論文、雑誌のレビュー。作者の発言だけに頼らない
- 評価と受賞: 発表時の反響、賞の選評、売上・視聴率。探す資料: 賞の公式発表、新聞・雑誌の批評、出版社・放送局の発表
- 翻訳と翻案: 日本語訳、映像化、舞台化、漫画化。探す資料: 各作品の公式サイト、書誌データベース
- 題材によって、成立と作風をまとめてよい。ライトノベルとテレビドラマでは、関連メディアや放送・配信を別の観点にする

## この類型の作法

- 現実世界の観点で書く。作品の内容、制作の過程、世に出てからの影響を分ける（R70）
- あらすじは現在形を基本にする。「第三章からは」のように作品の構成に触れず、制作者の視点（「作者はここで」）でも書かない（R71・R72）
- 一次資料だけで解釈しない。作品そのものと、作者・批評家・読者反応の二次資料の両方を使う（R73）
- 解釈・テーマ・影響は、二次資料に載っているものだけ書く。出典に書かれていない因果を作らない（R09）
- 登場人物・設定は簡潔にし、プロフィールや細部は書かない（R74）
- 評価語（「名作」など）を地の文で使わず、受賞・批評の出典で示す（R04・R05）
- 作品名は『』、作品の中の小題（章名・話名）は「」で括る（R28）
- 引用は短くする
- ネタバレを伏せず、注意書きも置かない
- 「余談」「トリビア」の節を作らない（R12）

## 細かい種類の差分

- `light-novel`（ライトノベル）: 「あらすじ → 登場人物 → 用語 → 作風とテーマ → 制作背景 → 評価 → 既刊一覧 → 関連メディア」の並びにする。導入部は「作家名による日本のライトノベル。イラストは○○が担当。レーベルより YYYY年M月から刊行」の順（R120）。物語の外（沿革、作者の意図、影響、反響）も書き、作品を知らない読者を前提にする。詳細すぎる要約や、書誌・設定の羅列で記事の大半を占めない（R121・R122）
- `tv-drama`（テレビドラマ）: 「概要 → あらすじ → 登場人物 → 製作 → 作品の評価 → スタッフ → 放送・配信 → 関連商品」の並びにする。導入部は「YYYY年M月D日から{枠}にて放送されたテレビドラマ。主演は X と Y」の順で、題名の由来を第二段落に置いてよい。出典は雑誌・評論家・新聞にし、一般人のブログ・SNS・まとめサイト・レビューサイトは使わない。芸能人の反応を一つずつ書かず、キャッチコピーを導入部や専用の節に置かない（R97）。放送の節は文章で経緯を書く（R94）

## 第一文の例

`『'''潮騒の手紙'''』（しおさいのてがみ）は、20世紀の日本の作家・水無瀬棹による中編小説。`
