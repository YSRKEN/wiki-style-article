# 動植物（`species`）

動物・植物・菌類など、生物の一つの種（または分類群）を題材にする型。哺乳類、鳥類、魚類、植物に使える。

Infobox は生物分類表で、分類の階層（界から種まで）、学名、保全状況などを入れる。項目は `sh wiki.sh type species` で原稿の雛形を出せる。

## 節の並び

骨格は「分布 → 形態 → 分類 → 生態 → 人間との関係」。動物と植物で入り方が違う。

動物（哺乳類・鳥類・魚類）の既定:

1. 分布: 生息地、分布の推移（絶滅危惧種では「分布とその推移」）
2. 形態: 大きさ、体の特徴
3. 分類（と系統）: 近縁種、亜種、分類の変遷
4. 生態: 食性、繁殖、行動
5. 発見の経緯: 新種として見つかった経過（資料があれば）
6. 人間との関係: 保全、文化。希少種では「保全状態評価」を小節か独立の節にするか、「希少種として」の節にまとめる。節名は「人間との関係」が多い

植物の既定:

1. 概要または名称・呼称: 植物は名称（和名の由来、別名）から入る記事と、概要から入る記事がある
2. 特徴（形態）: 大きさ、葉、花、実
3. 分類と系統: 資料があれば
4. 分布・生態: 生殖が重要な種では「生殖」「分布と伝播」を別の節にする
5. 人間との関わり: 利用（薬用・食用）、栽培、名称、文化。利用と文化を別の節（「利用」「社会や文化とのかかわり」）にする記事もある。小節の例は「薬用」「食用」「栽培」「名称」「季語・花言葉」

文化・利用の節は、種に関する出典があるものを精選する。自治体の木・鳥のような一覧は、範囲を絞った節にする。

## 導入部

第一文は目・科・属を順に書く。

- 動物: `'''和名'''（漢字表記、学名: 〜）は、{目}{科}{属}に分類される{哺乳類／鳥類／淡水魚}。`
- 植物: `'''和名'''（漢字表記、学名: 〜）は、{科}{属}の{多年草}の一種である。`

括弧には、漢字表記、学名の順で入れる。単型の属は「本種のみで{属}を構成する」と述べる。続く文は、分布、形態の特徴、保全状態か利用の順で要約する。絶滅危惧種は第二段落以降で保全状態を述べ、利用の多い種は利用を述べる。分類・分布・名称の根拠には、導入部でも出典を付ける（材料では導入部だけで脚注が 30〜50 件ほど付く記事があった）。段落数の集計は取っていない。全類型では 4 段落以内が大半なので、2〜3 段落を目安にする。

## 調べる観点の下敷き

- 分類・名称: 学名、和名の漢字表記、上位分類、近縁種、亜種、シノニム。探す資料の例: 一次は原記載の論文・分類学の改訂論文、二次は図鑑・分類学の総説・生物の標準和名を定めた目録
- 分布（推移）: 生息域、分布が変わった経緯。一次は政府・研究機関の調査報告、二次は図鑑・専門書
- 形態: 大きさ、色、体の構造、植物の器官。原記載、図鑑、研究論文
- 生態: 食性、繁殖、生活史、植物の生殖。研究論文、専門書、調査報告
- 発見の経緯・研究史（題材しだい）: 新種の記載、学会での取り扱い。原記載と、経緯を述べた書籍・報道
- 保全状態: 一次は政府・国際機関のレッドリストと、保護に関する法令、二次は保全活動の報告・報道。評価した機関と年を必ず確かめる
- 人間との関係: 利用（薬用・食用・栽培）、名称の由来、文化（郵便物の意匠、季語、自治体の木・鳥）。一次は公的機関や自治体の公式資料、二次は民俗・本草・事典

動物は「分布」「形態」「生態」を別の担当にしやすい。植物は「名称」と「利用・文化」を厚くし、利用の担当を分ける。保全が焦点の希少種は「保全状態」を独立の担当にする。

## この類型の作法

- 分類・学名・保全状態は変わる。いつの時点の分類か、どの機関のいつの評価かを書く。「現在」「近年」で示さない（R08）
- 分布は「日本では」「日本国外では」と基準を明示して書く。分布の推移は年代を入れる（R11、R08）
- 学名は導入部の第一文に和名の漢字表記と並べる。属名と種小名の順で書く
- 薬用・食用・毒性の記述は、効能や安全を地の文で断定しない。出典の記述として誰の資料かを書く（R01、R06）。書き手が成分と効能をつなげる推論をしない（R09）
- 「貴重な」「美しい」「希少な」のような評価語を使わず、レッドリストの区分や個体数の数字で示す（R05）
- 保全をめぐる論争や政策の評価は、論争に加わらず一つの客観的な記述にまとめる（R02）
- 文化・利用の節は雑多な豆知識の羅列にしない。種に関する出典があるものを、小節に分けて書く（R12）
- 動物と植物の既定の並びを混ぜない。植物に「発見の経緯」を足すのは、資料があるときだけ

## 第一文の例

`'''ミドリヒゲモリネズミ'''（緑髭森鼠、学名: Fabulomys viridibarbis）は、ネズミ目ネズミ科ヒゲモリネズミ属に分類される哺乳類。`
