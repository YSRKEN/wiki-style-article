# 場所（`place`）

城・河川・都市・施設・街道・消えた施設のような、地理上の場所や構造物を題材にする型。細かい種類: `castle`（城）、`river`（河川）、`mountain`（山）、`island`（島）、`lake`（湖）、`peninsula`（半島）、`road`（道路）、`railway-station`（鉄道駅）。節の並びはこのファイルに従い、Infobox だけが変わる。基本型の `place` は Infobox を持たない（種類ごとにテンプレートが違うため）。ここに挙げた種類に当てはまらない場所（博物館・競馬場など）は、`place` のまま Infobox なしで書く。Infobox の項目は `sh wiki.sh type place` で原稿の雛形を出せる。

## 節の並び

先頭は「概要」または「概説」を置く記事が多い。以降は題材の種類で並びが変わるので、既定は次のとおりにして、種類ごとの違いは下に書く。

1. 概要: 場所の位置づけを要約する（題材しだい。置かずに地理から始める記事もある）。
2. 名称（由来・別名）: 城・河川・都市に出る。由来や別名に資料があれば置く。
3. 歴史（沿革）: 時代ごとに小節を分ける。
4. 構造・地理: 城なら構造、河川なら地理・自然・水系、都市なら地理・気候・人口と行政分野ごとの節。
5. 施設・文化財・保護管理（資料があれば）: 指定された文化財、整備と管理、周囲の施設。
6. 交通・観光・現地情報（資料があれば）: 後半に置く。
7. 伝承・民俗・関連する人物・登場作品（資料があれば）: 個別の名前の節にする。

歴史と地理の前後は題材で違う。都市と城は 名称 → 歴史 → 地理（構造）、河川は 地理 → 自然 → 名称 → 水系 → … → 歴史の順。消えた施設は歴史が中心で、地理・交通の節を持たない。ある地域の歴史だけを扱う記事は、時代ごとの節を並べ、導入部で範囲を言う。「関連施設」という節名は使わず、「周囲の文化施設・観光名所」「〜を由来とする名称」のような個別の名前にする。

## 導入部

```
'''名称'''（読み）は、{都道府県}{市}にある{種別}。
```

- 河川は源流から河口まで一文で書く（「水源を〜として〜を流れ、〜に注ぐ一級河川。」）。
- 都市は正式名称を太字の主題にし、通称は次の語として示す。
- 消えた施設は存続期間を第一文に入れる（「1906年から1910年まで〜に存在した」）。
- 別名・異名は太字で第一段落に入れ、由来の詳細は本文の「名称」の節に譲る。
- 日本の場所は、国宝・重要文化財・特別史跡のような文化財指定の名称を導入部で挙げる。
- ある場所の歴史だけを扱う記事は、第一文で「〜について詳述する」と範囲を言う。
- 段落数は1〜4段落。第一段落で位置づけ、続く段落で歴史の要約と現状を書く。

## 調べる観点の下敷き

- 基本情報（所在地・種別・規模・指定）: 管理者・自治体の公式サイト、指定を出した機関の公表、国土地理院などの地図。
- 名称と由来: 地名の研究書、自治体史、辞典類。
- 歴史・沿革: 自治体史、発掘調査報告書、史料、郷土史の書籍、新聞の過去記事。
- 構造・地理・自然: 公的機関の統計（流域面積、延長、人口など）、調査報告書、専門書、ガイドブック。
- 文化財・保護管理・整備: 文化財の指定記録、管理者の公表資料、修理の報告書。
- 利用・交通・観光（現地情報）: 管理者の公式サイト、交通事業者の案内。変わりやすいので時点を確かめる。
- 伝承・民俗・登場作品・関連する人物: 民俗誌、郷土史、作品そのもの、批評・紹介記事。

題材しだいで合わせてよい。小さな場所は「歴史」と「名称」を1人にまとめ、都市のように大きな場所は行政分野ごと（地理・気候・人口・経済・交通など）に担当を分ける。

## この類型の作法

- 現地情報（開城時間・料金・交通）は後半に置く。変わりやすいので、書くなら時点を年月で添え、要点に絞る（R08、R13）。
- 日本の記事は、文化財指定の名称を導入部で挙げる。
- 「〜である」で終わる文が、他の類型より多くなる（状態の説明が中心のため）。歴史の節は過去形で書く。
- 座標は、Infobox に緯度経度の欄があるテンプレートが多い。座標を付ける記事もある。
- 都市は行政分野（法制、治安、経済、金融、文化、教育、医療、交通など）ごとに節が増える。分量は出典での扱いに合わせる（R03）。
- 城は構造と修理の歴史が厚く、河川は施設・水質・開発が厚い。題材の厚みに合わせて節の重さを変える。

## 細かい種類の差分

- `castle`（城）: 名称の由来と別名 → 歴史・沿革 → 構造 → 修理の歴史 → 世界遺産登録・文化財 → 整備と管理 → 現地情報 → 周囲の文化施設・観光名所 → 伝承・登場作品。構造と修理の歴史を厚く書く。第一文は `'''名称'''（読み）は、{都道府県}{市}にある日本の城。`。文化財の指定名称を導入部で挙げる。
- `river`（河川）: 地理 → 自然 → 名称 → 水系 → 河口 → 歴史および開発史 → 河川施設 → 水質 → 交通 → 観光 → 民俗 → 関連する人物 → 〜を由来とする名称。地理から始め、歴史は後ろに置く。第一文は水源から河口までを一文で書き、別名は太字で第一段落に入れる。
- `mountain`（山）: 概要 → 地理 → 地質・地形 → 気候と植生 → 歴史（信仰と登山史）→ 登山 → 周辺の施設 → 文化・作品。標高・山系・種類を Infobox に置き、初登頂や噴火の記録は「歴史」の節に書く。第一文は `'''月影岳'''（つきかげだけ）は、月影県と霧原県の境にある標高2,880 mの山である。`。
- `island`（島）: 概要 → 地理（位置・面積・地形）→ 気候と植生 → 歴史 → 産業 → 交通 → 住民と文化 → 関連する作品。離島は航路と空路の節を分ける。第一文は `'''霧原島'''（きりはらじま）は、月影県の沖合にある面積120 km²の島である。`。
- `lake`（湖）: 概要 → 地理（位置・面積・水深）→ 水質と成因 → 生態系 → 歴史（治水と開発）→ 漁業と観光 → 周辺の交通 → 関連する作品。淡水か汽水かを冒頭で述べ、成因（断層湖・カルデラ湖など）は「水質と成因」の節で説明する。第一文は `'''月影湖'''（つきかげこ）は、月影県霧原市にある面積32 km²の湖である。`。
- `peninsula`（半島）: 概要 → 地理（位置・面積・地形）→ 気候 → 歴史 → 産業と生活 → 交通 → 観光 → 関連する作品。付け根の位置と属する国・地域を冒頭で示し、面する海域は「地理」の節で述べる。第一文は `'''月影半島'''（つきかげはんとう）は、月影県の南西に突き出した面積210 km²の半島である。`。
- `road`（道路）: 概要 → 路線データ → 地理（通る市町村）→ 歴史 → 改良と現状 → 交通量 → 沿道の施設 → 関連する作品。起点・終点と延長を冒頭の一文に入れ、指定区間や重複区間は「路線データ」の節に書く。第一文は `'''月影街道'''（つきかげかいどう）は、月影県霧原市を起点とし、同県湖畔町に至る延長24.5 kmの道路である。`。
- `railway-station`（鉄道駅）: 概要 → 駅の構造（ホームと改札）→ 利用状況 → 歴史（開業・改良・周辺開発）→ 駅周辺 → 接続する路線と交通 → 関連する作品。所在地と事業者を冒頭の一文に入れ、乗車人員の推移は Infobox に収録していないので本文に文章で書く。第一文は `'''月影駅'''（つきかげえき）は、月影県霧原市にある月影鉄道本線の駅である。`。

## 第一文の例

`'''月影湖畔庭園'''（つきかげこはんていえん）は、月影県霧原市にある日本庭園。`
