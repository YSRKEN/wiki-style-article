# 競走馬（`racehorse`）

競走馬として走った個々の馬を主題にする記事に使う。引退後に種牡馬になった馬も、この型で書く。細かい種類は無い。Infobox の項目は `sh wiki.sh type racehorse` で原稿の雛形を出せる。

## 節の並び

競走馬の節構成に、定まった方式は無い。執筆の指針は「馬の特性に合わせる」と定めている。骨格は「生涯 → 成績 → 特徴・評価 → 血統」で、言及の多い話題（種牡馬の節、騎手、批判）は独立した節にする。

1. 概要: 導入部に収まらない背景がある馬だけに置く（題材しだい）。種牡馬として大きな実績のある馬で置く記事がある。
2. 生涯: 時期ごとの h3 に分ける（必ず置く）。小節は「誕生・デビュー前」「競走馬時代」「引退後」「死後」を基本にする。故障や手術の経過が大きい馬は、その経過を小節にする。競走馬時代と引退後を、生涯の下でなく、それぞれ独立した節にして小節を並べる記事もある。
3. 成績: 競走成績を書く。種牡馬としての成績があれば、同じ節の小節に分ける。主な競走は 1 競走 1 行の箇条書き（年月日・競走名・着順）で書き、全成績は並べない（原稿は表を書けない）。
4. 特徴・評価: 小節に「身体面」「知能・精神面」「レーススタイル（走法）」「競走馬名および愛称・呼称」「投票における評価」を立てる。多くの記事に共通するが、資料のある小節だけを置く。
5. 種牡馬として・産駒: 種牡馬として実績のある馬は、「種牡馬として」を独立の節にして小節に分け、「産駒」「母の父としての産駒」を続ける。実績の少ない馬は、生涯の「引退後」の小節で済ませる。
6. 題材しだいの節: 「人気」（社会的な人気、グッズ、顕彰）、「騎手」、批判があった馬は批判を主題にした節（出走の間隔やローテーションを巡る批判など）、「エピソード」（挙げるなら、時期ごとに本文へ織り込むことを先に考える）。
7. 血統: 父・母・母の父と、血統の背景を散文で書く（必ず置く）。原稿は表を書けないので血統表は作らない。
8. 関連作品: 馬を描いた作品（資料があれば）。

## 導入部

第一文の型:

```
'''馬名'''（欧字名:Xxxx Xxxx、YYYY年M月D日 - YYYY年M月D日）は、日本の競走馬、種牡馬。
```

- 括弧に入れる順は、欧字名 → 生年月日 → 「 - 」→ 没年月日。年は西暦だけで書き、和暦を括弧に添えない。
- 執筆の指針は、第一文を主題の定義（馬名・原語名・生没年・時代・活躍地・種類）にし、第二文にその馬の価値をもっとも代表する事実を書き、第三文にその他の勝ち鞍や種牡馬としての評価を書くとする。
- 引退後でも「元競走馬」とは書かない。「サラブレッド」と書く必要もない。
- 段落数の目安は 2〜5 段落。第二段落にデビューと主な勝ち鞍、愛称を書き、第三段落以降に引退後と死を書く。
- 年齢を旧表記（数え年）で書く記事がある。どちらで書くかは資料の表記で確かめ、記事の中でそろえる。

## 調べる観点の下敷き

- 誕生とデビューまで: 生産牧場、購買や育成の経緯、馬主、調教師、デビュー前の評判。一次資料は競馬主催者・生産者・馬主の公式の記録とデータベース。二次資料は競馬専門誌・新聞の記事、書籍。
- 競走成績とレースごとの経過: 全出走の結果、勝ったレース、敗れたレース、騎手。一次資料は主催者のレース結果の公式データベース。二次資料は新聞・専門誌のレースの記事。
- 引退後・種牡馬・死: 引退の経緯、種牡馬としての成績と主な産駒、余生、死因と死後の扱い。一次資料は種牡馬の繋養先や生産者の発表。二次資料は専門誌・新聞・書籍。
- 特徴・評価: 馬体、気性、走法、レースのスタイル、愛称の由来、年度代表馬や顕彰などの投票の結果。二次資料の専門誌・評論・関係者の証言を中心にし、評価は誰が述べたかを控える。
- 血統: 父母とその系統、近親の活躍馬。一次資料は血統登録の公式データベース。二次資料は血統の解説書・専門誌。
- 人間関係と批判（題材しだい）: 騎手・調教師・馬主との関係、出走の判断を巡る批判。言及が多い話題は、別の担当に任せる。
- 人気と関連作品（題材しだい）: 社会的な人気、グッズ、顕彰、題材にした作品。二次資料は新聞・雑誌・書籍。

分け方: 競走成績と、引退後・種牡馬は、別の担当にするとよい。血統は、種牡馬としての実績が小さい馬では他の観点と合わせてよい。

## この類型の作法

- 節の並びは馬の特性に合わせる。種牡馬としての記述、騎手、批判のように、記述の多い話題は独立した節にする。少ない話題は独立させない。
- 引退後が長い、または種牡馬として実績のある馬は、「引退後」を生涯の小節で済ませず、「種牡馬として」「産駒」を独立の節にする。
- 特徴・評価の小節は、資料がある観点だけを置く。評価や人気は、投票・受賞・専門家の言葉のように検証できる形で書く。
- 年は「1985年3月27日」の形で書く。和暦を括弧書きにしない。
- 脚注は、馬の記事では個別の出典を引く方式が多い。数値（着順、タイム、馬体重）と出来事の経過に出典を付ける。
- 「エピソード」の節に雑多な逸話を並べない。時期ごとに本文へ織り込む。

## 第一文の例

```
'''ミツボシレグルス'''（欧字名:Mitsuboshi Regulus、1991年4月6日 - 2015年2月11日）は、日本の競走馬、種牡馬。
```
