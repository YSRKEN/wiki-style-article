# ネットミーム（`meme`）

ネット発の流行・俗語・都市伝説・話題になった表現（ネタ、合言葉、CM の台詞、実在した流行など）を扱う。語の意味や学術的な枠組みが中心なら `concept`、実在した事故・事件が中心なら `event`。

この型は Infobox を持たない。`sh wiki.sh type meme` で原稿の雛形を出せる。

## 節の並び

骨格は「概要（語義・内容）→ 起源 → 広まり → 反響・評価 → 考察・分析 → 関連作品」。本文の h2 は 3〜7 個と少なく、記事も短い。

1. 概要: 語義・内容。俗語と流行では置かず、「発祥と語義」「活動と用語」から始める記事もある
2. 発祥・経緯: 起源。最初の投稿・放送・刊行の日時と場所を特定して書く。節名は「発祥の経緯」「発祥と語義」「初期」など
3. 広まり: ネットでの拡散、メディアでの紹介、ブーム化と終焉。節名は「ネットでの広まり」「メディアでの紹介によるブーム化」「ブームの終焉」など
4. 反響・評価: 報道・識者・調査会社の分析を、出典の種類ごとに並べる。「メディアの分析と評価」「識者の分析と評価」「民間における調査」のように出典の種類を節名にする記事がある
5. 考察・分析: 語の成り立ち、広まった理由の分析（資料があれば）
6. 〜を扱った作品: 題材を扱った作品（資料があれば。都市伝説・流行の記事に多い）

題材の種類による差。

- 俗語: 「発祥」「語義」「分析」を持つ
- 流行: 「歴史」「商業展開」「反応」「社会的影響」を持つ
- 都市伝説・創作: 「発祥の経緯」「ネットでの広まり」「反響」「考察」「〜を扱った作品」を持つ
- CM・番組由来: 「内容」「スタッフ」が加わる

## 導入部

第一文は、題材の種類で型が変わる。

- 俗語・ネットスラング: `'''X'''（読み）とは、〜を意味する俗語である。` （または「インターネットスラングである」）。第二文で派生元の語と時期を示す
- 実在した流行・出来事: `「X」（読み）とは、〜に端を発した論争である。` / `〜に出没したといわれる中年男性。` 時期と場所を付ける
- 都市伝説・創作: `'''X'''は、日本のインターネットコミュニティ等において、都市伝説として語られている架空の〜である。`

実在か創作かが論点なら、導入部でその論点を述べる。使う範囲を限定するなら第二文に書く（「本記事では〜も述べる」）。段落数の集計はミーム単独では取っていない。全類型では 1 段落が最多で、この類型は記事が短いため 1〜2 段落を目安にする。

## 調べる観点の下敷き

- 語義・内容: 何を指す語・話か。探す資料の例: 辞典・事典の項目、解説記事、書籍
- 起源: 最初の投稿・放送・刊行物の日時と場所。一次は掲示板のログ・番組・刊行物そのもの、二次は起源を検証した報道・解説記事・書籍。一次だけで日時を決めない
- 広まりとブーム化: 拡散の経路、メディアでの紹介、流行語の選考、ブームの盛衰。二次は新聞・雑誌・ニュースサイトの記事
- 報道・識者の評価と分析: 誰がどう分析したか。二次は報道、識者の論考、書籍
- 調査・数値: 民間の調査会社・自治体・大学などの調査。公表元、調査年、対象を確かめる
- 派生・商業展開・影響: 商品化、ゲームなどへの影響、題材を扱った作品。一次は公式サイトや作品そのもの、二次は報道
- 実在か創作か（題材しだい）: 都市伝説・実在した流行で論点になるとき、検証した報道・研究を集める

流行・商業展開が主なら「広まり」と「派生・商業展開」を厚く、都市伝説なら「起源」と「実在か創作か」を厚くする。起源と広まりは同じ担当にまとめてよい。

## この類型の作法

- 出典を SNS・掲示板・個人ブログの投稿そのものにしない（R10）。起源の日時・経緯、広まり、評価は、報道・解説記事・書籍で裏づけられるものを書く。投稿を見つけても調べの手がかりにとどめ、裏づけのない日時や経緯は書かない
- 評価は誰の分析かを書き、報道・識者・調査を出典ごとに並べる（R01、R06）。「話題となった」「有名な」のような評価語で広まりを言わず、報道の件数・調査の数値・商品化などの事実で示す（R05）
- 実在か創作かが論点の題材は、導入部で諸説あることを述べる。架空の事柄は、架空であることが分かるように書く（R40）
- 存命の個人が絡むとき（流行の発端になった人、投稿者、取り上げられた人）は、出典のない否定的な記述を書かない（R61）。私人は知名度に釣り合う情報だけを書く（R62）
- ブームの時期は年月で書く。盛衰を述べるときも「最近」「現在」を使わない（R08）。単発の話題を、出典での扱いより大きく書かない（R03）。速報にしない（R13）
- 「その他」「余談」の節を作らない（R12）。材料の記事に「その他」を置く例はあるが、内容は該当する節に文脈を付けて織り込む
- 題材の語や発言の引用は「」で括る。俗語・隠語は、題材として「」で示す場合のほかは地の文で使わず、普通の語で説明する（R30）
- Infobox を作らない

## 第一文の例

`'''月曜のカレー係'''（げつようのカレーがかり）とは、職場や学校で週の初めに当番の人物を指して使われる、日本のインターネットスラングである。`
