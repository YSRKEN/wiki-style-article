# 組織・企業・団体（`organization`）

企業・団体・クラブ・グループなど、人が集まって活動する組織を題材にする型。細かい種類: `band`（バンド）、`comedy-duo`（お笑いコンビ）、`soccer-club`（サッカークラブ）、`government-agency`（行政機関）、`academic-body`（学術団体）。節の並びはこのファイルに従い、Infobox だけが変わる。Infobox の項目は `sh wiki.sh type organization` で原稿の雛形を出せる。

## 節の並び

骨格は「概要 → 沿革（歴史）→ 現在の事業・組織 → 評価・影響」。沿革が最大の節になる。

1. 概要: 組織の位置づけ、事業の全体像、規模。
2. 沿革（歴史）: 時期区分の小節に分け、小節の見出しに年の範囲を入れる。出来事は年順に並べる。20を超える小節になる記事もある。
3. 事業・組織・活動: 業種ごとに独自の節を立てる。企業なら「企業概説」、航空会社なら「機材」「路線展開」「サービス」「運賃」、団体なら「理念と目的」「組織構成・構成員」「運営費」「国際活動」「国内活動」「刊行物」。
4. 評価・影響: 節名は「功績」「波及効果」「評価・影響」と呼ぶ。「反響」は組織の記事で使われていない。
5. トラブル（資料があれば）: 不祥事や事故。出典での扱いの大きさに合わせる（R03）。
6. 関連する作品（資料があれば）。
7. 歴代の長（資料があれば）: 会長・長官のような歴代の長は一覧で書く。

並びは記事ごとに割れる。団体では「沿革」を事業の節より後ろに置く記事もある。無い節は作らない。

## 導入部

```
'''正式名称'''（英語名など）は、{国}の{業種}企業。
```

- 第一文に国と業種を入れる。団体なら「{国}の{種別}」にする。
- 廃業した組織は「かつての」と過去の位置づけを書き、後継の組織との関係を第二文で述べる。
- 続く文で、設立年、沿革の要約、規模、主要事業を述べる。クラブなど数字で示せるものは、創設年やタイトル数を数字で書く。
- 括弧には読み・英語名などを入れる。略称は括弧内か次の文で示す。
- 導入部は1〜4段落。

## 調べる観点の下敷き

- 基本情報（正式名称・設立・種類・所在地・代表者）: 組織の公式サイト、登記や法令上の公表資料、官公庁の発表。
- 沿革: 社史・団体史、新聞・雑誌の過去記事、周年の刊行物。
- 事業・組織・活動の内容: 公式の事業報告、組織図、業界誌、統計。業種に固有の節（機材・路線・組織構成など）もここで集める。
- 規模と実績（売上・シェア・会員数・タイトル数）: 有価証券報告書や官公庁の統計などの公的資料。自社の発表だけを根拠にしない（R130）。
- 評価・影響: 業界誌、新聞・雑誌の論評、書籍、受賞の記録。
- トラブル・論争: 新聞報道、判決、調査報告。扱いの重さは出典に合わせる（R03）。
- 人物（創業者・代表者・メンバー・歴代の長）: 人名事典、本人の公式の経歴、報道。存命の人物は作法の規則を当てる。

題材しだいで、小さな組織は「基本情報」と「沿革」を1人にまとめる。沿革が長い組織は、時期ごとに担当を分ける。

## この類型の作法

- 存命の創業者・代表者・メンバーに触れる箇所は、存命人物の規則を当てる。出典のない否定的な記述は書かない（R61）。ゴシップ・私生活は、著名性に関わるものを信頼できる第三者の出典で書く（R62）。著名でない人物の正確な誕生日は書かず、誕生年だけにする（R63）。
- 組織の記事は、その組織と関係のない第三者が公表した資料で検証できることを土台にする。自社の発表やプレスリリースだけを根拠にしない（R130）。
- 「業界を代表する」「革新的な」のような評価語を地の文に置かない。売上・シェア・受賞などの事実で示す（R131）。
- 販売価格・仕様・リリースノートを逐一並べない（R132）。
- 上場企業の主要株主を書くなら、有価証券報告書提出会社は上位10名、信託口は括弧に注記、所有株式数でなく割合で書く（R133）。
- 沿革の小節の見出しに年の範囲を入れる。出来事は年順に並べる。
- 組織の種類ごとの独自の節を立てる。クラブはタイトル・ユニフォーム・スタジアム、行政機関は組織構成・運営費、バンドは楽曲制作・ライブが入る。

## 細かい種類の差分

- `band`（バンド）: 先頭は「メンバー」、次に来歴（時期ごとの小節）→ 楽曲制作 → 評価・音楽性 → 作品（ディスコグラフィ）→ ライブ → 定期連載・出演。概要で名前の由来・表記を書く記事もある。導入部は `'''名'''（読み）は、日本の4人組バンド。YYYY年に結成、YYYY年にメジャーデビュー。YYYY年に解散した。` のように、結成・デビュー・解散を短い文で並べ、代表曲や記録を数字で続ける。存続中なら所属事務所とレコード会社を続ける。
- `comedy-duo`（お笑いコンビ）: メンバー → 歴史（芸歴）→ 芸風 → 作品構造 → 評価・影響 → 公演 → 出演 → 出版。受賞歴を節にする記事もある。導入部は1段落で短く、`'''コンビ名'''は、{メンバー}による{コントグループ／日本のお笑いコンビ}。` に活動形態、結成の経緯、所属事務所と結成年を1〜2文続ける。公演名・ネタ名は「」で括る記事が多い。「エピソード」の節は作らず、本文に織り込む（R12）。見本が少ないので、型を固く当てすぎない。
- `soccer-club`（サッカークラブ）: 名称・愛称 → 歴史（時期ごとの小節。強豪は多数）→ タイトル → 成績 → エンブレム → ユニフォーム → スタジアム → ライバル → サポーター → 記録 → 歴代監督。解散した歴史的チームは 概要 → 沿革 → 戦績 → 在籍した選手と短くする。導入部は `'''クラブ名'''（原語）は、{国}の{地名}をホームタウンとするプロサッカークラブ。`、2段落目に創設年とタイトル数。記録の一覧が中心の記事より、歴史を散文で書く型を優先する。
- `government-agency`（行政機関）: 概要（所掌事務）→ 沿革 → 組織（幹部・内部部局・施設等機関・地方支分部局）→ 財政 → 職員 → 所管法人 → 庁舎 → 歴代の長（一覧）。導入部は `'''名称'''（読み、略称: X）は、{国}の行政機関のひとつ。` に上部組織を続ける。括弧に原語名を入れる。議会は仕組み（議場・議事・委員会・選挙）を先に書く並びだが、組織の変種としてこの型に寄せてよい。
- `academic-body`（学術団体）: 概要 → 理念と目的 → 組織構成・構成員 → 運営費 → 国際活動 → 国内活動 → 刊行物 → 沿革 → 年表。歴代の会長・副会長は一覧の小節にする。導入部は `'''名称'''（読み、略称: X）は、{国}の{国立アカデミーなどの種別}。` のように、種別と位置づけを書く。導入部に出典を多く付ける記事がある。

## 第一文の例

`'''月影製菓'''（つきかげせいか、英: Tsukikage Confectionery）は、日本の菓子メーカー。`
