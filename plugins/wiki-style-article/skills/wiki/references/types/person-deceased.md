# 人物（故人）（`person-deceased`）

すでに亡くなった個人を主題にする記事に使う。生涯に加えて、死後の評価や顕彰も書く対象になる。

細かい種類: `voice-actor`（声優）、`singer`（歌手）、`baseball-player`（野球選手）、`soccer-player`（サッカー選手）、`pro-wrestler`（プロレスラー）、`actor`（俳優）、`author`（作家）、`manga-artist`（漫画家）。節の並びはこのファイルに従い、Infobox だけが変わる。Infobox の項目は `sh wiki.sh type person-deceased` で原稿の雛形を出せる（細かい種類は、その ID を渡す）。

## 節の並び

良質記事の並びを既定にする。生涯 → 作風・人物 → 評価 → 作品・受賞の一覧の順。ただし家族を受賞より前に置く記事や、死後の節を生涯の直後に置く記事もある。

1. 生涯: 時期や転機ごとの h3 に分ける（必ず置く）。小節名は時期、転機、代表作の名前（作品名を見出しに入れる記事もある）のどれかにする。小節名に月・年の範囲を括弧で添える書き方もある。節名は「生涯」「来歴」「人物・来歴」の揺れがあり、題材の資料の呼び方に合わせる。諸説のある事柄は「諸説」の小節を立てて扱う。
2. 作風: テーマ・方法・製作や執筆の仕方（資料があれば）。職業に合う小節名にする。
3. 人物: 性格・信条・人間関係（資料があれば）。
4. 評価・影響: 同時代の評価と後世の評価を分ける。故人の記事では独立の節にする記事が多い。
5. 家族: 親族・系譜（資料があれば）。
6. 死後: 慰霊祭・記念館・文学碑や追悼碑・顕彰・題材にした作品、本人を演じた俳優（資料があれば）。
7. 年譜: 生涯の節が長いとき、略年譜を別の節に添える（資料があれば。本文の主体にはしない）。
8. 受賞歴: 受賞を年順に並べる。
9. 作品・出演の一覧: 職業に合わせて「作品」「おもな作品」「出演作品」「フィルモグラフィ」などを置く。年ごと・分野ごとの h3 に分ける。
10. 関連人物・関連書籍: 本文で触れた人物と、評伝や研究書（資料があれば）。

## 導入部

第一文の型:

```
'''氏名'''（読み、生年月日〈和暦〉 - 没年月日〈和暦〉）は、国の職業。本名は'''本名'''（読み）。
```

- 括弧に入れる順は、読み → 生年月日 → 「 - 」→ 没年月日。和暦は、日本の人物なら山括弧に入れる（二重の丸括弧を避けるため）。外国人は和暦を付けず、原語綴りを括弧に入れる。
- 本名・旧姓・別名は、第一段落か第二段落で書く。表記揺れのある名前は第二段落で説明する。
- 第二段落以降は、代表作・受賞・歴史的評価を述べ、続いて経歴を要約する。
- 段落数の目安は 2〜4 段落。導入部にも出典を付ける（R41）。

## 調べる観点の下敷き

- 生い立ち・修業期: 出身地、家族、学歴、きっかけ。一次資料は本人の自伝・日記・書簡・戸籍や公的な記録を引いた研究書。二次資料は評伝、年譜つきの研究書、新聞・雑誌の記事。
- 活動の経過（時期ごと）: デビュー、転機、代表作、所属や拠点の変遷。一次資料は作品そのもの・当時の発表・全集の年譜。二次資料は評伝・研究書・当時の新聞記事。
- 作風・人物像: 作風とテーマ、制作の方法、性格、交友。二次資料の批評・研究・関係者の回想を中心にし、本人の発言は出どころを控える。
- 評価と影響: 同時代の評と後世の評、後続への影響。二次資料の批評・研究書・事典類。評価は誰が述べたかを控える。
- 晩年・死・死後: 最期の経過、慰霊・記念館・顕彰、題材にした作品や本人を演じた俳優。一次資料は顕彰施設の公式ページ。二次資料は新聞記事・研究書。
- 作品・出演の一覧と受賞: 職業に合う一覧と受賞歴。一次資料は全集・公式の目録・主催者の発表。二次資料は専門のデータベース、書誌。
- 諸説の整理（題材しだい）: 説が分かれる事柄は、誰がどんな根拠で述べたかを説ごとに控え、別の担当に任せる。

分け方: 生涯が長い人物は、時期で担当を分ける。作品の一覧が大きい人物は、分野ごとに分ける。

## この類型の作法

- 第一段落に、名前・称号、生年月日と没年月日、国籍または地域、主な活動、重要である理由を入れる。日本人は日本人と明記する（R50）。
- 名前は太字。日本人・中国人などは名字と名前の間に半角空白を置き、直後に（読み、生年月日 - 没年月日）を続ける。「○代目」には読みを振らない。欧米人は片仮名の名を書き、直後の括弧に現地語のフルネームを入れる（R51）。
- 生没年は「生年月日 - 没年月日」の形にする。分かる範囲で書き、不正確なら「1600年ごろ」とする。明治5年以前は西暦と和暦を併記し、旧暦の月日は「2月10日 (旧暦)」の形にする。グレゴリオ暦の実施（1582年10月15日）以降はグレゴリオ暦、それ以前はユリウス暦で書く（R52）。
- 通称・ペンネームは第一段落に書く。本人が公開していなかった本名は書かない（R53）。
- 敬称は冒頭で紹介するときにとどめ、以降の文では使わない（R54）。故人に「故」を付けない（R30）。
- 君主・教皇・大統領・首相など国のトップは、在位・在職期間を第一段落に書く（R55）。
- 血液型のような、業績や特筆性に関係しない些末な個人情報を導入部に入れない（R56）。
- 本文は流れのある文章で書く。年譜（箇条書きかどうかを問わず）を記事の主体にしない。略年譜を別に添えるのはよい（R57）。
- 生涯の小節は、時期・転機・代表作を見出しにする。節の長さは出来事の重さに合わせる。
- 死後の扱い（慰霊、記念館、評価、題材にした作品）は、資料が厚ければ独立の節にする。
- 諸説のある事柄は「諸説」の小節で扱い、どの説も主語と出典を付けて並べる。

## 細かい種類の差分

- `voice-actor`（声優）: 来歴の次に「出演」の節を置き、作品の種類ごとに h3 に分ける（テレビアニメ、劇場アニメ、OVA、Webアニメ、ゲーム、ドラマCD、ラジオドラマ、吹き替え、ラジオ、テレビ番組、映像商品、ナレーションの順。該当するものだけ）。各行は古いものから発表順に `* 作品名（2015年、役名）` の形にし、複数の役は読点で区切る。続けて「ディスコグラフィ」「ライブ・イベント」を置く。代表作は出典で示せるものに限り、本名は書かない。見本の秀逸・良質記事が無い類型で、この並びは執筆指針による。
- `singer`（歌手）: 生涯を時期ごとに厚く書く。後ろに「代表曲」「ディスコグラフィ」「主な出演」を置く。日本の歌手は「NHK紅白歌合戦出場歴」の節を持つ記事がある。本人を題材にした作品や演じた人物の節を置く記事もある。曲名は「」、番組・映画・アルバムの題は『』で括る。
- `baseball-player`（野球選手）: 生涯をアマチュア時代・球団ごとに分け、「選手としての特徴」の後に、「詳細情報」の節へ年度別成績・タイトル・表彰・記録・背番号をまとめる。導入部は所属した球団とデビュー・主な実績を述べる。
- `soccer-player`（サッカー選手）: 生涯の代わりに「生い立ち」「クラブ経歴」「代表経歴」（大会ごとの h3）「引退後」を置く。後ろに「獲得タイトル」「個人成績」を置く。
- `pro-wrestler`（プロレスラー）: 生涯の後に「得意技」「タイトル歴」「入場テーマ曲」「プロレス観」を置く。導入部は所属した団体とデビュー・主な実績を述べる。
- `actor`（俳優）: 「生涯」を時期ごとに分け、「評価」を演技と容姿のように観点で分けてよい。後ろに「出演作品」（年ごと）、「受賞歴」を置く。本人を演じた俳優の節を置く記事もある。
- `author`（作家）: 「作風・文学主題・評価」を厚くし、後ろに「おもな作品」「刊行書籍」を置く。分野の多い作家は「SF」「推理小説」「ノンフィクション」のように分野ごとの節を立て、続けて「代表的著作」を置く。題材にした作品、肉声資料の節を置く記事もある。
- `manga-artist`（漫画家）: 生涯を出来事や連載の節目ごとに分ける。「作風」「執筆スタイル」を置き、後ろに「年表」「受賞歴」「作品リスト」を置く。故人の漫画家は材料に見本が無く、存命の漫画家の並びに「評価」「死後」を足して使っている。

## 第一文の例

```
'''波多野 志津'''（はたの しづ、1921年〈大正10年〉5月2日 - 1987年〈昭和62年〉11月19日）は、日本の作家。本名は'''波多野 静江'''（はたの しずえ）。
```
