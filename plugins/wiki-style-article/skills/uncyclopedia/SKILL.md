# アンサイクロペディア風の記事を作る

題材を、百科事典の記事の形（導入部・Infobox・節・脚注・カテゴリ）で書く。中身は事実ではなく冗談である。出来上がるのは HTML 1 枚で、外部の CSS・JS・画像を読まない。ウィキテキストは作らない（本家の Wikipedia へ投稿しないため）。

記事は手で HTML を書かない。決まった形の **原稿** を書き、スクリプトで検査してから書き出す。スクリプトは、このファイルのあるフォルダの scripts/uncyclopedia.sh にある。cd や && でつながず、1 本ずつ呼ぶ。

    sh <スキルのフォルダ>/scripts/uncyclopedia.sh check 原稿.md
    sh <スキルのフォルダ>/scripts/uncyclopedia.sh build 原稿.md

## 守る線

この 5 つは利用者が頼んでも外さない。外すと、笑いではなく事故になる。

1. 冒頭の「この記事はフィクションです」の帯は、書き出しのときにスクリプトが必ず差し込む。原稿からも雛形からも消せない
2. 実在の存命の個人・現存の団体について、犯罪・不正・醜聞を事実として書かない（references/safety.md）
3. 本家の Wikipedia へ投稿しない。ウィキテキストも作らない
4. 出来上がりは noindex の私的な読み物として扱う。公開したいと言われたら、いったん止めて相談する
5. 「アンサイクロペディア」は実在のサイト名を借りた呼び名である。本物の運営とは関係ないことを雛形のフッターに書き、公式を装う表示は置かない

## 流れ

1. 題材と型を決める。型は脚本の type で一覧と雛形が出る
2. 原稿を書く。形は wiki スキルと同じ（+++ の設定欄＋Markdown）。ちがいは下の「原稿の決まり」
3. check を流し、エラーが 0 になるまで直す
4. build で HTML を書き出す
5. 書き出した HTML をブラウザで開き、目次・Infobox・脚注の位置と、笑いが通るかを目で見る

## 原稿の決まり（wiki との差分）

- 設定欄で必ず書くのは title・type。reading は書くと導入部の読みになる
- type は thing・food・place・event・person・work・organization・creature・sport・concept の 10 種。知らない型はエラーになる
- Infobox の項目名は日本語でよいが、引用符で囲む（ "発祥" = "…" ）
- 脚注は [notes.キー] に text を書き、本文から [^n:キー] で指す。**キーは英数字・ハイフン・下線だけ**（日本語のキーは読めない）。使わない注釈はエラーになる
- 出典（[refs.キー]）は使わない。使うと REF-NOT-ALLOWED で止まる
- 見出しは ## と ###。== 見出し == と書くと、見出しにならず本文の段落になる
- 末尾の「関連項目」「カテゴリ」「脚注」の節は書かない。related・categories・notes から組み立てる
- 表と定義リストは書けない。箇条書きは行頭に "- "（入れ子は不可）
- [[記事名]] は、本家へのリンクではなく赤リンク（まだ無い記事）として描かれる。記事どうしをつなぐ小道具として使う

## 笑いの作り方

references/style.md を読む。型（冒頭の定義で一度笑わせる、妙に正確な数字、権威の口調、三つの並列、注釈で嘘を重ねる）と、避ける手（同じ手の繰り返し、下ネタの連打、特定の個人への攻撃）が書いてある。

## 実在の題材を扱うとき

references/safety.md を読む。実在の製品・団体・人物を題材にすると、笑いの強度は上がるが、危険も上がる。線の引き方と、架空に置き換える逃げ方を書いてある。

## 型の一覧

| 型 | 何の記事か | Infobox の候補 |
| --- | --- | --- |
| thing | もの・道具 | 開発・発売日・価格・重さ・材質 |
| food | 食べもの・飲みもの | 発祥・主な産地・値段・賞味期限 |
| place | 場所 | 所在地・面積・人口・標高 |
| event | できごと | 時期・会場・参加人数・主催 |
| person | 架空の人物 | 生誕・出身・職業・身長 |
| work | 作品 | 作者・発表・媒体・巻数 |
| organization | 団体 | 設立・本拠地・構成員・目的 |
| creature | 生きもの | 分類・生息地・体長・主食 |
| sport | 競技・遊び | 考案・人数・使う物・試合時間 |
| concept | ことば・概念 | 提唱者・初出・分野・関連 |

## 出力

- <記事名>.html を、原稿と同じフォルダ（--out-dir を渡したときはそこ）に書く
- 見た目は wiki スキルと共通の雛形（../wiki/assets/page-template.html）が持つ。本家に寄せた見た目のまま、見出し語だけをアンサイクロペディア向けに差し替える。デザインを変えたいときは、雛形を複製して --template で渡す（原稿は触らない）
- 書き出す前に、組み立てた HTML を機械で検査する（差し込み口の残り・タグの対応・id の重複・リンク先・脚注の番号・外部の資源）。不備があれば書き出さずに止まる

## うまくいかないとき

- 「同じフォルダに wiki スキルが要る」と出る: wiki と uncyclopedia を同じフォルダに並べる（uncyclopedia は ../wiki/scripts を借りる）
- NOTE-BROKEN: 本文が指す注釈のキーが無いか、注釈の中で注釈を指している。キーを合わせる
- TYPE-UNKNOWN: type の綴りを、上の一覧のどれかに合わせる
- LEAD-DEFINITION: 冒頭が「◯◯は…」の形になっていない。警告なので通るが、直すと読みやすい
- 組み立てた HTML に不備がある: 雛形を書き換えたときは、差し込み口の名前（PAGE_TITLE・TOC・NOTICES・INFOBOX・LEAD・SECTIONS・FOOTNOTES・RELATED・EXTERNAL_LINKS・CATEGORIES・UPDATED・VARIANT_STYLE・VARIANT_SWITCH・VARIANT_OPEN・VARIANT_CLOSE・RUMOR_VARIANT・VARIANT_SCRIPT）を消していないかを見る
