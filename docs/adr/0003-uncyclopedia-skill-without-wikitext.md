# アンサイクロペディア風の記事は、兄弟の別スキルにして、ウィキテキストは作らない

本家の記事の形を借りて、事実ではなく冗談を書く用途がある（アンサイクロペディアのような読み物）。呼び名は `wiki` に切り替えの印を足すのではなく、兄弟の `uncyclopedia` として分ける。原稿の形（+++ の設定欄＋Markdown）と、脚注の番号・段落の HTML 化・表記と構成の検査は `wiki` のものを借り、笑いの作り方と既定の見た目を別に持つ。

`wiki` に切り替えの印を足さないのは、呼び名が一つだと、どちらの約束で書いた原稿かが呼んだ文に埋もれるため。パロディでは出典を要求しない・本家へ投稿しない・冒頭にフィクションの帯を必ず出す、という三つの約束が通常の記事と逆になる。呼び名を分ければ、原稿を読む人がどちらの約束かを取り違えない。

ウィキテキストを書き出さないのは、本家の Wikipedia に載せてよい内容ではないため。HTML 1 枚だけを書き出す。

[[記事名]] は本家へのリンクにせず、赤リンク（まだ無い記事）として描く。存在しない関連記事を指すこと自体が冗談になり、本家の記事空間へ人を送らない。

見た目は二つ持ち、既定は本物のアンサイクロペディアの旧スキン風（このスキルの `assets/page-template.html`。左の欄に 🥔 のロゴと縦のメニュー、本文の中に目次の箱、Infobox は出さない）にする。もう一つは、`wiki` と共通の雛形（`../wiki/assets/page-template.html`）を借りて見出し語だけを差し替えた Wikipedia 風で、`build --look wikipedia` で選ぶ。書き出す前に、どちらにするかを利用者に聞く（2026-11-04 に利用者が決めた。2026-11-03 にいったん共通の雛形だけにしたのを改めた）。兄弟の `wiki` たちはそれぞれ本家のウィキペディアに見た目を寄せているので、`uncyclopedia` の既定も本物のアンサイクロペディアに寄せたほうが、並べたときに釣り合う。Wikipedia 風は、PR #7 の作者が見た目を `wiki` と共通の雛形に載せ替えた形に、🥔 のロゴと「執筆していません」のバナーをこちらで足したもので、選べる見た目として残す。

ウィキメディア財団の商標の方針は、本家の見た目をまねたサイトを作らないよう求めており（2026-11-02 に作者が確認）、Wikipedia 風を公開すればそこに触れる。だから出来上がりは、どちらの見た目でも noindex の私的な読み物に限り、本物ではない旨を画面の上とフッターに書く。

呼び名は「アンサイクロペディア」を名乗る（2026-11-02 に利用者の希望で決めた）。実在のサイト名を借りるので、どちらの見た目でもフッターに本物の運営とは関係ない旨を書く。

## Considered Options

- **`wiki` に「パロディ」の印を足す**: 呼び名は一つで済む。ただし、出典の有無・フィクションの帯の有無・ウィキテキストの有無が原稿ごとに変わり、検査の意味が薄れる。
- **`wiki-with-rumor` のように、調査の工程も共有する**: パロディは調べない。調査の工程を挟むと、事実を集めてから嘘を書く手順になり、書くことが事実に引っ張られる。
- **ウィキテキストも書き出す**: 出力の形はそろうが、本家へ投稿できる形のものを、投稿してはいけない内容で作ることになる。
- **本家の雛形を借りず、独自の雛形を用意する**: 商標の方針には触れにくい。ただし 2026-11-03 に利用者から「UI が全然 Wikipedia じゃない」と戻された。百科事典らしく見えない独自の見た目は採らず、本物のアンサイクロペディアに寄せた旧スキン風を既定にした。
- **共通の雛形だけにする**: 2026-11-03 にいったんこの形にした。雛形が一つで済むが、兄弟の `wiki` と見分けがつかず、アンサイクロペディアらしさが文面にしか出ない。

## Consequences

- `uncyclopedia` は `../wiki/scripts` を借りるので、三つの兄弟と同じく、四つを並べて置く必要がある。
- 検査は、表記（`check_notation`）と構成（`check_structure`、ただしトリビア節の規則は除く）を借り、型の未知・冒頭の定義・使われない注釈を足した。出典（`[refs.キー]`）を使うと止まる。
- フォルダ名（＝呼び出し名）は英字の `uncyclopedia`、画面の表示は「アンサイクロペディア」にした。フォルダ名は英字の方が道具をまたいで扱いやすく、表示は日本語の名のままで通る。
- 雛形は旧スキン風の 1 枚だけを持つ。Wikipedia 風は `../wiki/assets/page-template.html` を借り、見出し語・副題・フッターの断り書きだけを書き換える。見た目を変えたいときは雛形を複製して `--template` で渡す（`--look` より優先する。原稿は触らない）。
- 旧スキン風は Infobox を出さない。原稿の `[infobox]` は、Wikipedia 風を選んだときにだけ出る。
- 出来上がりは noindex の私的な読み物として扱う。実在の存命の個人・現存の団体の犯罪や不正を事実として書かない線は、`references/safety.md` に置いた。
