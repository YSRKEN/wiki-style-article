# 噂と考察は別の呼び名で、印と警告の枠を付けて載せる

本家の三本柱（中立的な観点・検証可能性・独自研究は載せない）に従うと、信頼できる資料に無い噂や利用者の考察は全部落ちる。試運転で、騒動を扱う題材の記事が報道で確かめられた範囲に絞られ、批判や推測の話は記事に書かれなかった（渡しの文でそう断っていた）。作者は、情報をまとめる道具としては足りないと判断した。そこで、噂と考察を載せる呼び名 `/wiki-style-article:wiki-with-rumor` を足し、`/wiki-style-article:wiki` は載せないままにした。載せるときは、関わる節の中に誰の見方かを示して書き、出どころの脚注と印（信頼性要検証・独自研究範囲など）を付け、記事の冒頭に警告の枠を貼る。本家には、記事の出典や中立性の問題を読む人に知らせる枠のテンプレート（観点・出典の明記・独自研究など）があり、その見え方に合わせた。

特定の人や会社への非難のような強い主張は、互いに写しでない出どころが 2 つ以上あるときだけ載せる。存命の人の私生活や犯罪の断定にも、例外は置かない（2026-11-02、作者の決定）。

## Considered Options

- **噂と考察を載せない（本家どおり）**: 一番安全だが、試運転のあと作者が足りないと判断した。`/wiki` としては残した。
- **一つの呼び名の中で、頼まれたら載せる・載せないを切り替える**: 呼び名は一つで済むが、どちらで書いたかが呼んだ文に埋もれる。呼び名で分けたほうが、選ぶときに迷わない。
- **噂と考察を専用の節にまとめる**: 確かな話との境は分かりやすいが、本家の記事にはあまり無い形で、それっぽさが下がる。
- **強い主張も出どころ 1 つで載せる**: 拾いは一番多いが、中立性を大きく欠く話が載りやすい。
- **存命の人の私生活と犯罪の断定は報道を要する**: 本家の存命人物の伝記の方針に近く、実在の人を傷つける恐れは一番小さい。作者は、出どころ 2 つの線だけにすることを選んだ。

## Consequences

- 原稿に印と、出典の信頼性の欄が要る。弱い出典を使った所に印が無ければ、検査で止める。
- `wiki-with-rumor` の記事は、出どころ 2 つの線を満たせば、実在の人への非難も載りうる。記事が AI の生成で未検証であり、Web に公開しないことは、README とページのフッタで伝える。
