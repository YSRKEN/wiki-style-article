# 記事の原稿を正にし、HTML とウィキテキストは原稿から書き出す

一つの記事を、ブラウザで読む HTML と、MediaWiki に貼るウィキテキストの二つの形で出す。AI はどちらも直接は書かず、節・段落・脚注・Infobox などを決まった形で書いた原稿だけを書き、スクリプトがその原稿から二つのファイルを書き出す。二つを別々に書かせると、片方だけ直したときに食い違いが残る。脚注のリンク先や目次の対応といった検査も、原稿の段で機械的に済ませられる。

## Considered Options

- **AI が HTML とウィキテキストを別々に書く**：作るのは一番早いが、二つの食い違いを防げない。
- **ウィキテキストを正にして HTML へ変換する**：本家の原稿に一番近い。ただし、日本語版のテンプレート（`{{Cite web}}`・各 Infobox）を手元で描くには、テンプレートごとに変換を自前で書くか、MediaWiki 本体と拡張（ParserFunctions・Scribunto・TemplateStyles）を手元で動かし、テンプレートと Lua モジュールを本家から取り込む必要がある。本家の API（`action=parse`）に描かせる方法もあるが、記事の中身を毎回外部へ送ることになり、ネットにつながっている必要もある。
